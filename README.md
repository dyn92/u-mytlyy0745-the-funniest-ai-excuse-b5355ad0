A deterministic Python program that writes the funniest one-line excuse an AI agent gives after failing a task: its tools behaved like uncooperative coworkers — the calendar said no, the database was on lunch, and the API hung up — so all it could do was ask nicely. Pure standard library, no network, same output every run.

## Run it

```sh
python3 main.py
```
